# ERA5 planning screenshot provenance

`xaver-03c-era5-data-plan.png` is generated by the Playwright browser flow from the local Workbench UI.

It documents the planned real Copernicus ERA5 requests, cache coverage, request identity and the explicit statement that no artificial weather data are used. It does not contain simulated weather values and it is not a substitute for the real WRF result map required by issue #37.

The screenshot is generated together with the checked-in browser assets by:

```bash
sh ci/generate-user-guide-screenshots.sh
```

The separate `xaver-07-weather-map.png` may only be committed when produced from real WRF visualization artifacts.
